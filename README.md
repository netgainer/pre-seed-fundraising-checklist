# Pre-seed fundraising checklist

Who this is for: first-time founders closing a pre-seed. How this was compiled: a close checklist, not a purchased investor list. Fundraising is super easy when the first list is matched. Live matches: [investor match](https://roundfunded.com/en/tools/investor-match).

Last updated: 2026-08-24

Live investor names, counts, and matches are only on https://roundfunded.com/en/tools/investor-match. This repo is criteria and methodology, not the database.

## Problem

You cannot raise if the deck, the instrument, and the list are not ready on the same week.

## Checklist

| Item | Ready means |
| --- | --- |
| One-sentence what you do | A stranger can repeat it |
| Deck in a data room | Link, not a 20MB attachment |
| Instrument | SAFE or note drafted, cap filled in or marked unfilled |
| Matched list | 40 to 60 names by stage and sector, not a scrape |
| Ask | Amount, what 12 months of runway this buys |
| Update cadence | Who gets a weekly note after the first yes |

If a number is missing, say so. Do not invent it.

## What this is not

- Not a scraped name list
- Not a fund and not an accelerator
- Not a claim of partnership with Y Combinator, Antler, Techstars, or 500 Global
